# Blueprint: Ministries Directory & Department Pages

## Page Overview
* **Purpose**: Showcase all 11 church departments (Kids, Youth, Young Adults, Men, Women, Worship, Outreach, Marriage, Prayer, Media, Seniors).
* **Target Users**: Families, youth, young adults, and members seeking involvement.
* **Main Goal**: Connect every demographic to an active ministry.

## Structure
1. `/ministries`: 11-department catalog grid.
2. `/ministries/[slug]`: Deep-dive landing page per department (meeting times, leader contact, gallery, sign-up form).

## Technical Specification
* **Typography**: Card Titles `20px SemiBold`, Descriptions `14px Regular`.
* **Icons**: `Baby`, `Flame`, `GraduationCap`, `Music`, `HeartHandshake`, `Users`, `ShieldCheck`.
* **Dependencies**: `next/image`, `lucide-react`.
