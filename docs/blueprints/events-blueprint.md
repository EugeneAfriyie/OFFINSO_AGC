# Blueprint: Events Calendar & Gatherings

## Page Overview
* **Purpose**: Display upcoming church events, summer camps, and fellowship meetings with 1-click calendar sync.
* **Target Users**: Members and local families.
* **Main Goal**: Increase event attendance and participation.

## Structure
1. Filter bar by department tag (Youth, Families, Seniors, Outreach).
2. Event list cards with date badges (Month/Day), time, location, description.
3. 1-Click "Add to Calendar" action (Google / Apple / Outlook).

## Technical Specification
* **SEO**: `Event` schema per card.
* **Dependencies**: `date-fns`, `lucide-react`.
