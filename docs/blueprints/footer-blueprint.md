## Technical & Visual Specification
* **Typography**: Column Headers `14px SemiBold` (`#FFFFFF`), Links `14px Regular` (`#94A3B8`).
* **Colors**: Deep Navy `#0F172A` background, Accent Blue `#38BDF8` hover link color.
* **Icons**: `Lucide: Facebook`, `Lucide: Instagram`, `Lucide: Youtube`, `Lucide: ArrowUp`.
* **Responsive Adaptation**:
  * *Desktop*: 5-column wide grid + bottom bar.
  * *Tablet*: 2-column x 2-row layout.
  * *Mobile*: Single vertical stack.
* **Accessibility**: `role="contentinfo"`, explicit `aria-label` tags.
* **Dependencies**: `lucide-react`.
